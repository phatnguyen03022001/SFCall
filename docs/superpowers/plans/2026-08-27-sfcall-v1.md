# SFCall V1 Implementation Plan

> **For agentic workers:** implement task-by-task with causal tests first.

**Goal:** Native-macOS-first call copilot whose durable memory preserves client/case requirements, evidence, decisions, and call history without depending on raw transcripts.

**Architecture:** `SFCallCore` owns deterministic domain state and local persistence contracts. Audio/STT/provider/HUD adapters remain outside the core so Apple, OpenAI, GLM, and DeepSeek can be swapped without changing case memory semantics.

**Tech Stack:** Swift 6.2, macOS 14+, XCTest/Swift Testing-compatible XCTest, SQLite adapter next, ScreenCaptureKit/Speech/AppKit later.

**Spec:** Approved conversation design: Client Memory + Case State + append-only Evidence/Events + Call Sessions; raw audio never stored by default; transcript retention is explicit.

## Global Constraints

- Client claims never silently rewrite confirmed baseline.
- Evidence and case events are append-only.
- Requirement ownership is CLIENT, USER, or MUTUAL.
- Material requirement changes require explicit confirmation before entering baseline.
- Raw audio retention defaults to NEVER.
- Transcript retention defaults to EPHEMERAL.
- Provider choice must not affect domain state.
